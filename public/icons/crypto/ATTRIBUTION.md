# Crypto-market icon attribution

The DOGE, SHIB, PEPE, and BONK SVGs in this directory are the branded token assets
from [Web3 Icons](https://github.com/0xa3k5/web3icons), downloaded on
2026-10-25. DOGE, SHIB, and PEPE came from that repository's
`raw-svgs/tokens/branded/` directory. BONK came from the same MIT-licensed
Token Icons Branded collection at
`https://svgicons.com/img/211043/bonk.svg`.

The upstream repository is licensed under the MIT License. The repository
also identifies logos and token names as their respective owners' trademarks;
these assets are used only to identify the market selected by the customer.

The WIF PNG was downloaded from the maintained Trust Wallet Assets CDN at
`https://assets-cdn.trustwallet.com/blockchains/solana/assets/EKpQGSJtjMFqKZ9KQanSqYXRcF8fBopzLHYxdM65zcjm/logo.png`
on 2026-10-25. Trust Wallet Assets is MIT-licensed. The mark is used only to
identify dogwifhat in the market selector.

The compact fallback badge is reserved for a newly eligible market whose logo
has not been legally verified yet. It is not presented as an official logo.
